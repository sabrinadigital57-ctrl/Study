# Study 📚

Une mini-application web pour transformer un cours en fiche de révision claire.

## Version 1

- Choix de la matière
- 4 formats de fiches
- Détection des notions, listes et définitions
- Questions pour se tester
- Copie de la fiche
- Impression / export PDF via le navigateur
- Fonctionne directement dans le navigateur, sans compte ni serveur

> Cette première version n'utilise pas encore de véritable modèle d'IA : elle organise le texte avec JavaScript. Une version avec IA pourra être ajoutée plus tard avec une architecture sécurisée.

## Fichiers

- `index.html` — structure de l'application
- `style.css` — design
- `script.js` — logique du générateur
